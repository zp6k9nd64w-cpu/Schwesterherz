# Schwesterherz

Elegante One-Page-Website für Hochzeitsmusiker, direkt für GitHub Pages geeignet.

## Eigene Inhalte einsetzen

- In `index.html` Platzhalter wie `[EURE NAMEN]`, E-Mail, Telefonnummer und Instagram ersetzen.
- In `styles.css` die beiden `background-image`-URLs gegen eigene Bild-URLs austauschen.
- Bei den Hörproben in `index.html` Titel und Beschreibung anpassen. Für echte Audios können die Play-Buttons später durch `<audio controls>` oder eigene Audio-Links ersetzt werden.

## Veröffentlichen mit GitHub Pages

1. Repository auf GitHub öffnen.
2. Unter **Settings → Pages** als Quelle den Branch `main` und den Ordner `/ (root)` auswählen.
3. Speichern. GitHub zeigt danach die öffentliche Website-Adresse an.

Die Seite benötigt keinen Build-Schritt und keine Installation.
